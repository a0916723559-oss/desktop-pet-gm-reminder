隱私權政策

適用工具：Desktop-Pet GM 操作紀錄提醒工具。更新日期：2026 年 10 月 26 日。

維護者為 GitHub 帳號 a0916723559-oss。本政策說明此 Windows 本機、個人使用提醒工具對資料的處理，不代替同一 Google Cloud 專案中其他工具的個別說明。

1. Google 資料與權限

本工具要求 gmail.send，用來寄送使用者安排的保存期限提醒與測試信；同時要求 openid 及電子郵件身分權限，確認授權帳戶，將同一帳戶設為寄件人及收件人。

工具實際使用與保存的授權資料包括：本人電子郵件地址、OAuth 用戶端設定、離線更新憑證、授權時間與已授予的權限範圍。存取憑證在執行時向 Google 更新，供當次寄信使用。

本工具不要求 Gmail 密碼，不讀取收件匣、既有郵件內容、郵件歷史或聯絡人，也不透過 Gmail API 刪除或整理郵件。

2. 使用目的

上述資料只用於本人授權、確認寄收件帳戶、更新授權，以及寄送本人安排的提醒或測試通知。工具不將 Google 使用者資料用於廣告、販售、信用評分、使用者側寫或 AI 模型訓練。

本工具對 Google API 資料的使用與移轉遵守 Google API Services User Data Policy，包括 Limited Use 要求。

3. 本機保存與安全措施

  • OAuth 憑證與帳戶設定以 Windows DPAPI 加密保存在目前使用者的 LocalAppData，與玩家存檔分開，不提交至 Git 或本網站。
  • 操作紀錄、寄信工作、時間、結果、錯誤類型與 Gmail 回傳的訊息 ID 保存在本機 SQLite 資料庫；一般操作紀錄不是加密資料庫，仍需使用者保護 Windows 帳戶及本機檔案。
  • 寄信結果紀錄不刻意保存存取憑證、更新憑證或用戶端密鑰；紀錄工具亦提供敏感欄位遮蔽。
  • 使用者自行下載的原始 OAuth 用戶端 JSON 仍由使用者保管，其檔案不因本工具加密授權資料而自動加密或刪除。
  • 工具與 Google 的授權及 API 通訊使用 HTTPS；瀏覽器授權回應使用限於本機 127.0.0.1 的回呼、狀態檢查及 PKCE。

4. 傳送及第三方服務

進行授權或寄信時，必要的授權請求、寄收件地址及工具產生的通知內容會傳送給 Google，由 Gmail 處理並寄給同一個授權帳戶。工具不把玩家存檔或 GM 操作紀錄附加到提醒信，也沒有另外接收這些資料的工具營運方伺服器。

此說明網站由 GitHub Pages 託管，沒有加入分析或廣告程式，也不在頁面收集 Google 登入資料。網站託管服務可能處理一般連線資訊，詳見 GitHub 隱私權聲明；Google 服務另適用 Google 隱私權政策。

5. 保存、刪除與撤銷授權

操作紀錄不會因保存期限提醒而自動刪除。使用者可在 GM 操作紀錄視窗匯出資料，並在確認後手動刪除紀錄。授權憑證及寄信工作狀態會留在本機，直到使用者自行移除或更新。

使用者可透過 Google 帳戶的第三方連線管理 撤銷授權，並視需要停用 Windows 排程及移除本機加密憑證。撤銷或刪除憑證後，後續提醒將無法寄送，直到再次取得有效授權。

手動刪除本機資料不會刪除已經寄到 Gmail 的郵件。若將本機紀錄匯出、另做備份或公開到 Issues，這些副本由使用者另行管理；工具不會自動回收或清理。

6. 聯絡與政策更新

問題或資料處理疑問可透過 專案 Issues 聯絡維護者；公開留言請勿提供密碼、憑證或私人紀錄。若資料用途或權限改變，維護者應先更新本政策及相關說明，並在需要時重新取得使用者同意。
