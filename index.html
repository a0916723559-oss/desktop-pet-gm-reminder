Desktop-Pet GM 操作紀錄提醒工具

這是一項供專案維護者個人使用的 Windows 本機工具，用來安排 GM 操作紀錄的保存期限提醒，以及本人明確安排的一次性寄信測試。

程式使用本人授權的 Gmail 帳戶寄信給同一個帳戶，提醒維護者檢查紀錄、匯出需要的資料，並自行決定是否刪除或調整保存方式。

工具如何運作

  • GM 操作紀錄保存在 Windows 本機，與遊戲玩家存檔分開。
  • Windows 工作排程器依設定時間啟動寄信程式，遊戲本身不必保持開啟。
  • Gmail API 只用於寄送本人設定的提醒與測試通知，寄件人和收件人相同。
  • 程式不讀取收件匣、郵件歷史或聯絡人，也不把遊戲存檔與操作紀錄附加到提醒信。
  • 工具不會自動刪除操作紀錄，也不提供代替其他人批量寄信的服務。

Google 授權用途

工具要求 Gmail 寄信權限，以及確認授權帳戶電子郵件身分所需的 OpenID／Email 權限。授權由本機工具開啟 Google 官方登入頁，由使用者親自同意；本網站不提供登入表單，也不收取 Gmail 密碼。

此提醒工具使用的 Google Cloud OAuth 專案品牌名稱為 AI-Announcement-Translator，專用桌面用戶端名稱為 Desktop-Pet GM 寄信。本頁說明的是 Desktop-Pet 的提醒功能。

資料與使用者控制

授權憑證以 Windows DPAPI 加密後保存在目前 Windows 使用者的本機資料夾，沒有工具營運方的雲端帳戶或資料儲存伺服器。寄信仍需要可用的 Google 授權、網路與符合條件的 Windows 登入環境；程式不保證授權永遠有效。

資料種類、用途、保存方式、第三方服務及撤銷方式，請閱讀 隱私權政策。
